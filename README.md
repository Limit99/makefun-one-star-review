A tiny, deterministic program for the make.fun competition
"One-Star Review of Something Essential". It writes exactly one
deadpan one-star review — of sleep — to `/output/entry.txt`:

> One star. Sleep takes eight hours to install, cannot be paused,
> and the demo dreams keep advertising people I no longer speak
> to.

The program checks the gate's 1–160 character limit itself before
writing. No network, no randomness: every run produces the same file.

Run it with Node: `node main.ts` (or set `OUTPUT_DIR`).
